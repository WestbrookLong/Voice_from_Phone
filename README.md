# 手机实时输入到 Windows 光标

手机打开电脑提供的网页后，在输入框中打字或使用手机输入法语音输入，电脑会把变化实时写入当前光标位置。

## 使用

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python server.py
```

启动后终端会打印类似地址：

```text
http://192.168.1.20:8787/?token=xxxx
```

手机和电脑连到同一个局域网，用手机浏览器打开该地址。先把电脑光标放到目标输入框，再在手机页面输入即可。

## 行为说明

- 手机端无需点击发送，输入框变化会自动同步。
- 语音输入法如果在句子结束后修正前文，电脑端会从差异位置开始退格并重打一段尾部，普通追加仍是即时流式输入。
- 手机端换行会在电脑端执行 Enter。
- 删除文字会在电脑端发送对应数量的 Backspace。
- 清空手机输入框只会重置手机端会话，不会删除电脑上已经输入的内容。
- 普通权限程序无法稳定向管理员权限窗口输入；如需输入管理员窗口，请用管理员权限运行本服务。

## Windows 桌面客户端

不想每次打开命令行时，可以运行：

```powershell
python desktop_client.py
```

界面会显示手机访问地址，并提供复制按钮。手机 App 或网页版都可以使用这个地址连接。

桌面客户端也会显示连接二维码。新版手机 App 点击“扫码连接”后扫描二维码，会自动填充电脑地址和 Token。

如果要分享给别人使用，推荐直接分享 `dist/VoiceInput.exe`。打包说明见 `PACKAGING.md`。

## 移动端远程

电脑端启动服务后，桌面客户端会显示 `移动端远程地址`，也可以切换显示对应二维码。

在手机或平板上用浏览器打开这个地址后，会看到电脑主屏幕画面。用 Apple Pencil 或触控在画面上按下和滑动时，电脑端会注入鼠标按下、移动和抬起事件。此模式可用于 Photoshop 等软件中已经选好的绘图工具。

移动端远程页面右下角有键盘按钮。点击后会弹出系统输入法，在输入框中输入的文本会注入到电脑当前文字光标处，仍然使用前缀匹配逻辑适配输入法修正。

双指在移动端远程画面上上下滑动会映射为电脑端鼠标滚轮。

如果双指滚轮识别不稳定，可以点击左下角“点击模式/滚轮模式”按钮切换。滚轮模式下，单指上下滑动会直接映射为电脑端鼠标滚轮。

点击左下角“蒙版关/蒙版开”可以开启本地绘画回显。开启后，移动端会立即显示一层临时笔迹蒙版，笔迹会自动淡出；电脑端仍然照常接收绘图动作。

蒙版旁边可切换清除策略：`自动淡出` 会按时间逐渐清除本地轨迹；`等屏幕响应` 会在收到下一帧电脑屏幕画面后清除本地轨迹。

当前限制：

- 只模拟鼠标按下和划线，不模拟 Apple Pencil 压感。
- 当前捕获主屏幕。
- 使用局域网 JPEG WebSocket 推流，低延迟优先，但还不是 WebRTC/H.264 级别。
